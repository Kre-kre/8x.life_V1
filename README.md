# 8x.life redesign

A dependency-free responsive homepage concept. It can be deployed to any static host without a build step.

## Run locally

Open `index.html` in a static web server from this folder, or deploy these files directly:

- `index.html`
- `styles.css`
- `app.js`
- `assets/` (the approved co-founder images)

## Replaceable content

The data arrays at the top of `app.js` hold the carousel media, team cards, build cards, traits, rules, and Network Deck links. Replace those values when approved 8x material is available.

`Join the platform` is wired to `https://8x.careers`. The remaining network links deliberately use only safe, known destinations and are marked for replacement as needed.
